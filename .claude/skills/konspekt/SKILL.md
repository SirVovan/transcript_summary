# Скилл: Обработка транскрипта выступления

## Файлы скилла

- `preprocessor.py` — статистика, нарезка транскрипта (ШАГ 0), отрезка чанка по границам сегмента (Фаза 2)
- `tov_spec.md` — ToV-спецификация (базовые правила + динамический блок)
- `audience_spec.md` — описание целевой Аудитории (единый адресат для всех агентов)
- `subagent_phase1.md` — инструкции для субагентов Фазы 1 (черновая сегментация, роль методолога)
- `subagent_phase2.md` — инструкции для субагентов Фазы 2 (написание текста, роль спикера + читательская самопроверка)
- `brigadir.md` — глобальный обзор, верификация, гармонизация, переходы, реконструкция, траектория, сборка мастер-MD, финальная самопроверка
- `kartograf_profile_*.md` — профили контента (справочник; детальная переработка — отдельный спек)
- `layer2_widget.md` — виджет (Слой 2, конвертация мастер-MD → JSON → HTML)

---

## Пайплайн

```
Транскрипт
    ↓
ШАГ 0: Оценка длительности (preprocessor.py info)
    ↓
    ├─ если ≤ 60 мин ──────────────────────────────────→ один чанк (транскрипт целиком)
    │
    └─ если > 60 мин
                ↓
          Нарезка на чанки (~60 мин каждый)
    ↓
ФАЗА 1: Субагенты — черновая сегментация (1 или N параллельно)
    ↓
БРИГАДИР: Глобальный обзор → чистовая карта
    ↓
ФАЗА 2: Субагенты — написание текста (по одному на сегмент, параллельно)
    ↓
БРИГАДИР: Верификация + гармонизация + переходы + реконструкция + сборка
    ↓
Мастер-MD → transcripts/
```

## ШАГ 0: Запуск

### Сбор контекста

Выполнить автоматически, без вопросов к пользователю:

1. Проверить `transcripts/` на наличие `*_мастер.md` — для серийного контекста.
   Если найдены — прочитать и сообщить одной строкой.

2. Запустить:
   ```
   python .claude/skills/konspekt/preprocessor.py info [путь к транскрипту]
   ```
   Получить оценку длительности (или токенов, если тайминга нет).

Затем задать пользователю **одним сообщением**:

```
1. Имя спикера (если не указано в транскрипте)
2. Профиль контента:
   - [ ] Лекция
   - [ ] Custdev-интервью
   - [ ] Встреча / синк
   - [ ] Конференция / конференс-доклад
   Если не уверен — Claude определит автоматически по транскрипту.
3. Режим работы:
   - Автоматический (без промежуточных проверок)
   - С проверкой (показывать чистовую карту перед Фазой 2; показать мастер-MD в конце)
```

Начинать работу только после получения ответов.

### Выбор пути

| Длительность | Действие |
| --- | --- |
| ≤ 60 мин (или ≤ 12K токенов без тайминга) | Один чанк — транскрипт целиком, без нарезки |
| > 60 мин (или > 12K токенов без тайминга) | Нарезка — `preprocessor.py windows` + `split` |

## ШАГ 1: Подготовка чанков

**Если один чанк:** нарезка не нужна. Транскрипт целиком используется как единственный чанк в Фазе 1.

**Если нарезка нужна:**

1. Запустить:
   ```
   python .claude/skills/konspekt/preprocessor.py windows [транскрипт]
   ```
   Получить окна (~2–3K токенов) вокруг потенциальных точек нарезки.

2. Для каждого окна: найти смысловую границу — конец мысли, абзаца.
   - Уверен → зафиксировать таймштамп, продолжить.
   - Не уверен → показать окно пользователю, объяснить неясность, запросить таймштамп.

3. Запустить нарезку:
   ```
   python .claude/skills/konspekt/preprocessor.py split [транскрипт] --at HH:MM:SS,HH:MM:SS,...
   ```
   Получить chunk-файлы (~60 мин каждый, перекрытие ~500 токенов).

---

## Динамический ToV

Прочитать первые ~2–3K токенов транскрипта. Выделить характерные обороты спикера, темп, фирменные фразы. Записать как `[TOV_DYNAMIC]...[/TOV_DYNAMIC]` блок (~150–200 токенов).

---

## Фаза 1: Черновая сегментация (параллельно)

Запустить по одному субагенту на каждый чанк, параллельно.

Прочитать `subagent_phase1.md` и передать его содержимое каждому субагенту в начале промпта.

Каждый субагент получает:
- `[CHUNK]` — содержимое своего chunk-файла (или транскрипта целиком, если один чанк)
- `[SERIAL CONTEXT]` — краткий серийный контекст (если есть мастер-MD предыдущих частей)
- `[PROFILE]` — профиль контента

Результат: черновая карта чанка (список сегментов с метаданными).

---

## Бригадир: Глобальный обзор

Прочитать `brigadir.md` и `audience_spec.md`. Выполнить раздел «Глобальный обзор — методолог»:
- Получить черновые карты всех субагентов
- Применить смысловой критерий (один сегмент = одна самостоятельная мысль автора); сигналы смены режима использовать как маркеры потенциальной границы
- При неопределённости — точечно прочитать фрагмент транскрипта
- Выдать чистовую навигационную карту
- Выполнить «Самопроверку — глазами Аудитории (сегментация)» (заменяет старые №1 и №2)

Если режим «с проверкой» — после самопроверки показать чистовую карту пользователю, ждать «ок».

---

## Фаза 2: Написание текста (параллельно)

Перед запуском субагентов: для каждого сегмента из чистовой карты вырезать его отрезок транскрипта по таймштампам сегмента:

```
python .claude/skills/konspekt/preprocessor.py slice [chunk-файл сегмента] --from HH:MM:SS --to HH:MM:SS
```

Получить `[CHUNK_сегмента]` — только тот отрезок транскрипта, который соответствует границам сегмента. Это резко сокращает входной контекст каждого writer'а (от полного чанка ~12K токенов до ~2–3K на сегмент).

Запустить по одному субагенту на каждый сегмент из чистовой карты, параллельно.

Прочитать `subagent_phase2.md` и передать его содержимое каждому субагенту в начале промпта.

Каждый субагент получает:
- `[NAV MAP]` — полная чистовая карта
- `[TOV SPEC]` — содержимое `tov_spec.md` + динамический блок ToV
- `[SEGMENT SPEC]` — запись своего сегмента из чистовой карты
- `[CHUNK_сегмента]` — отрезок транскрипта по границам сегмента (вывод `preprocessor.py slice`)

Результат: `### Карта` + `### Текст` для каждого сегмента.

---

## Бригадир: Сборка

Прочитать `brigadir.md` (и `audience_spec.md`, если ещё не загружен). Выполнить разделы по порядку: «Верификация текста», «Гармонизация стиля», «Переходы между сегментами», «Логическая реконструкция — методолог» (с самопроверкой), «Траектория — методолог» (с самопроверкой), «Сборка мастер-MD — редактор», «Финальная самопроверка мастер-MD — глазами Аудитории». После каждой самопроверки бригадира — применить найденные правки до перехода к следующему шагу.
