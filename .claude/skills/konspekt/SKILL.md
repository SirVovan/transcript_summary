# Скилл: /konspekt

Один проход Claude: транскрипт → мастер-MD.

## Файлы скилла

**Мастер-режим**

- `SKILL.md` — этот файл: роутер режимов и общая дисциплина.
- `master.md` — методология мастер-режима (ШАГ 0–4), читается по `/konspekt <транскрипт>`.
- `format_master.md` — контракт мастер-MD (шапка, шаблон сегмента, разделители, промпты, реконструкция); читают и master, и Слой 2.
- `profile_base.md` + `profile_*.md` — профили контента по типу выступления; нужный читается в ШАГ 0.
- `split_transcript.py` — нарезка длинного транскрипта на части по смысловым швам (ШАГ 0.3).
- `source_passport.py` — паспорт источника из Obsidian Clipping (ШАГ 4).
- `storage-paths.json` — единственный источник путей хранилища.

**Виджет (Слой 2 + Слой 3)**

- `layer2_widget.md` — сборка виджета, читается по запросу; `layer2_frames.md` — opt-in ветка кадров, только по команде «с кадрами».
- `layer3_recon.md` — кастомизация первого экрана виджета; `recon_patch_template.py` — шаблон патча.
- `md_parser.py` — мастер-MD → dict; `widget_generator.py` — dict → HTML.
- `frames_extract.py` + `frames_schema.json` — извлечение и отбор кадров видео (ветка кадров).
- `validate_widget.py` — PostToolUse-хук валидации JS виджета.

**Preview**

- `preview.md`, `preview_profiles/`, `preview_repost_sources.md` — режим предварительного обзора.
- `youtube_to_srt.py` (+ `cookies_spec.py`) — штатный инструмент получения транскрипта из YouTube (см. `preview.md`, ШАГ 0.2). Использовать его, а не сторонние `yt-dlp`/самопальный парсер VTT.

**Тесты**

- `tests/` — pytest по парсеру, генератору, кадрам, нарезке, route-блоку, паспорту; запускать вручную.

## Команды пользователя

- `/konspekt` + транскрипт → мастер-MD.
- `/konspekt — сделай виджет из <файл>` → виджет: Слой 2 + Слой 3 одним процессом (см. `layer2_widget.md`, затем `layer3_recon.md`).
- `/konspekt — сделай виджет с кадрами из <файл>` → **opt-in** ветка кадров: тот же виджет плюс извлечение ключевых кадров видео (слайды/промпты/инфографика) с распознаванием и встраиванием (см. `layer2_widget.md`, затем `layer2_frames.md`). Обычный «сделай виджет» — без кадров.
- `/konspekt preview <путь или YouTube-URL>` → предварительный обзор видео (см. `preview.md`).
- `/konspekt split <файл> [--target-min N]` → **ручная** нарезка транскрипта на части (см. «Ручная нарезка» ниже). Без обработки в мастер-MD — только режет файл.

## Мастер-режим

`/konspekt <транскрипт>` → прочитать **`master.md`** и идти по нему (ШАГ 0–4). Формат выходного файла — `format_master.md`.

---

## Дисциплина

- **Не использовать TodoWrite** — пайплайн линейный, прогресс виден из текста сообщений.
- **В режиме master — не запускать subagents/deferred tools** (один проход в основном агенте). Это правило именно master-режима. **Ветка кадров (Слой 2) — исключение и, наоборот, требует делегирования:** весь vision-объём (просмотр, триаж, распознавание слайдов и промптов) обязан идти на Codex→Sonnet-субагентов; Опус кадры сам через `Read` не смотрит — см. «Железное правило стоимости» в `layer2_frames.md`.
- **Дешёвая модель вместо дорогой (железное правило).** Если часть работы может сделать более дешёвая модель (Codex/Sonnet/Haiku) или субагент — делегировать, а не выполнять Опусом. Массовое распознавание изображений и однотипную механику — всегда делегировать. Чтение пачки картинок главным Опус-потоком = прожог 5-часового лимита и парализация пользователя; это ошибка, а не «оптимизация качества».
- **Нарезка длинного транскрипта — детерминированным скриптом `split_transcript.py` (ШАГ 0.3), без субагентов.** Скрипт считает равные целевые точки и режет файл; выбор конкретного смыслового шва в окне делает основной агент. Части обрабатываются последовательно как серия. Внутри одной части чанкования нет — она пишется одним проходом.

## Виджет (Слой 2 + Слой 3)

Когда пользователь просит виджет из мастер-MD — это **единый процесс из двух шагов, без остановки между ними**:

1. **Слой 2** — прочитать `layer2_widget.md`, сгенерировать виджет из мастер-MD.
2. **Слой 3** — сразу следом прочитать `layer3_recon.md`, оживить первый экран (левая колонка «взгляд сверху» + правая «Артефакты урока»).

Слой 3 — **не отдельный опциональный этап.** «Виджет» по умолчанию означает виджет с оживлённым первым экраном. Не выделять Слой 3 в отдельный запрос и не спрашивать, нужен ли он.

Мастер-MD должен уже существовать в рабочей папке серии до начала.

## Ручная нарезка (`/konspekt split`)

Когда пользователь пишет `/konspekt split <файл> [--target-min N]` — это **утилита**, не пайплайн мастер-MD: скрипт только режет транскрипт на части, обработки в мастер-MD нет.

Отличие от авторезки (ШАГ 0.3): запускается **по явной команде пользователя при любой длительности**, и размер фрагмента задаёт пользователь через `--target-min` (по умолчанию 90). Допуск +10 мин действует и здесь: при `--target-min 30` файл ≤ 40 мин не режется.

**Алгоритм — тот же, что в ШАГ 0.3:**

1. `python "$HOME/.claude/skills/konspekt/split_transcript.py" info "<файл>" --target-min N` — сколько частей.
2. `... windows "<файл>" --target-min N` — окна вокруг целевых точек.
3. Выбрать швы по правилу из вывода (вперёд 5–10 мин → иначе строго назад; не резать посреди темы).
4. `... split "<файл>" --at <шов1>,<шов2>,...` — создаёт `<имя>_ч1.txt … _чN.txt`.
5. Отчитаться путями к частям. В мастер-MD не обрабатывать (если пользователь не попросил отдельно).

## Режим `preview`

Когда пользователь пишет `/konspekt preview <путь или YouTube-URL>` — это **отдельный режим**, не часть пайплайна мастер-MD.

**Алгоритм:**

1. Прочитать `preview.md`.
2. Дальше действовать **только по `preview.md`**, не читая `master.md` и `format_master.md` (правила сегментации, шаблон сегмента, ToV, три уровня (И)/(М)/(Д), самопроверка — это правила режима `master`, к обзору они не применяются).

`preview.md` самодостаточный — содержит весь шаблон обзора, дисциплину, граничные случаи, инструкцию по работе с YouTube.

**Связь с режимом `master`:** односторонняя через **рекомендацию** в финальном разделе обзора. Автоматический переход в `master` не делается — пользователь вызывает `/konspekt <путь>` отдельной командой.
