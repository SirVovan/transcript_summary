# Нейропросвещение

- **Реальный автор:** Рома Райт (ASR часто слышит «Райд» — правильная форма «Райт»)
- **Канал:** Нейропросвещение
- **Тип источника:** прямой

## Заметки

- **Тематика:** Claude Code и агентные системы — команды, субагенты, hooks, MCP, skills, графы знаний (graphify), вайб-кодинг; обзоры релизов и сравнения агентов (Claude Code, Codex, OpenClaude / «мимокод»).
- **Формат:** обучающие обзоры-демонстрации с экрана, ровный темп, мало воды; регулярные приглашения в свой бесплатный закрытый клуб и отсылки за чеклистом/материалами в описание видео (мотать).
- **Папка воркспейса:** все обзоры этого канала — в `previews/nejroprosveschenie/` (одна папка на канал, не по папке на видео).
- **Особенности распознавания:** ASR стабильно корёжит ключевые термины:
  - Claude Code → «плод-код / клод-код / клодко / кд-код / СД-код / колод-код»
  - Cowork → «коворк / коворка»
  - loop (команда автономного режима) → «GOL / гол / луп»
  - graphify → «граpifй / графиifй / графай / grapify»
  - OpenClaude / opencode → «OpenCl / OpenClow / Онклоб / мимокод»
  - Codex → «Кодек / кодекс»
  - claude.md → «клод MD / clot.md / clod.md»
  - skills → «скилы / skкил / матерски skкил» (мастер-скилл)
  - имя автора → «Рома Райд» (правильно — Рома Райт)
