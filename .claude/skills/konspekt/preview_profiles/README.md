# Профили каналов/авторов (preview)

Папка с профилями источников для режима `/konspekt preview`. Профиль — это память
о канале/авторе, чтобы при **повторном** обзоре заполнять шапку без вопросов и
учитывать особенности распознавания.

## Когда подтягивается

ШАГ 2.2 preview-режима ищет профиль, когда обзор с источника делается **повторно**:

- **Прямое видео** (настоящие метаданные) — ключ по `channel_id` (надёжнее) или
  имени канала.
- **Перезалив** (метаданные фейковые) — ключ по имени реального автора, которое
  назвал владелец.

Если профиль найден — его поля (реальный автор, канал) заполняют шапку обзора без
уточняющих вопросов, а заметки помогают чистить искажённые распознаванием
имена/термины.

## Когда создаётся

**Не молча.** Если автор новый, а обзор по нему уже не первый — preview предлагает
владельцу завести/дополнить профиль. Создаётся только после согласия.

## Формат файла

Имя файла: `<slug>.md` (латиница/транслит, по каналу или автору).

```markdown
---
channel_id: UCxxxxxxxxxxxxxxxxxxxxxx   # для прямых видео; у перезаливов опустить
---

# <Канал или Автор>

- **Реальный автор:** <имя>
- **Канал:** <название канала>
- **Тип источника:** прямой / перезалив

## Заметки

- **Тематика:** <о чём канал>
- **Формат:** <лекции / разборы / стримы …>
- **Особенности распознавания:** <как чистить искажённые этим автором имена и
  термины — например, частые ослышки и их правильные формы>
```

Поле `channel_id` во frontmatter — ключ для прямых видео. Для перезаливов канал
YouTube фейковый, поэтому `channel_id` не указывается, а профиль находится по имени
автора.
