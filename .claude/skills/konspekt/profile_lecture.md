ПРОФИЛЬ: LECTURE
━━━━━━━━
Для: лекции, обучающие видео, вебинары, мастер-классы, спринты.

Принцип сегментации:
Делить по смысловым темам и переходам между ними.
Ориентир — смена темы, введение нового понятия, переход к практике.

Лекции с единым архитектурным замыслом (частый формат):
Многие практикумы/мастер-классы построены так: у автора есть сквозной
замысел урока — последовательность ЭТАПОВ, по которым он ведёт слушателя
к результату, — и он периодически прерывается на обратную связь от
аудитории (вопросы из чата/зала, перекуры). Если урок такого типа:
- Содержательные сегменты формулировать как ШАГИ единого процесса, не
  как ярлыки тем: заголовок = «Этап N — <глагол-действие>: <короткая суть>»
  (например, «Этап 2 — настроить рабочее место: settings.json, расширения»).
  Нумерация сквозная через все содержательные сегменты — она и делает
  заголовки отражением единого архитектурного процесса.
- Если часть урока углубляет один из этапов (вся часть = одна фаза метода) —
  нумеровать под-шагами этой фазы: «<фаза>, шаг N — <действие>: <суть>».
- Q&A/перекуры в нумерацию этапов НЕ входят — они паузы между этапами,
  заголовок «Ответы на вопросы — <по сути вопросов>».
- Тест: прочитать заголовки содержательных сегментов подряд (пропустив
  Q&A) — должен складываться маршрут единого замысла, а не оглавление.
- Преемственность между частями серии: держать тот же паттерн нумерации
  и стиль заголовков, что в предыдущих `*_мастер.md` серии. Конкретный
  маршрут метода и формулировки этапов — в `tov_<серия>.md`, сверяться с ним.
- **Маршрут до сегментации:** до нарезки на сегменты формируется раздел
  `## Замысел и маршрут` (см. `SKILL.md` ШАГ 1.3). Опорная структура из этого
  блока диктует границы и заголовки сегментов в 1.4.

Блоки обратной связи (Q&A) — отдельные сегменты:
Практикумы и лекции, где спикеру важна обратная связь, часто идут
ритмом «блок изложения → пауза на вопросы из чата/зала → следующий блок».
Эти Q&A-паузы выделять в самостоятельные сегменты с типом «Вопросы / ответы»,
не растворять в соседнем содержательном блоке.
- Граница — по сигналам спикера: «открою чат», «вижу комментарии»,
  «отвечу на вопросы», смена режима с изложения на реакцию.
- Короткая реплика-вставка в одну фразу — НЕ отдельный сегмент (анти-маркер).
  Отдельный сегмент — когда реально отведён блок на разбор нескольких вопросов.
- Тему формулировать по сути разобранных вопросов, не «ответы на вопросы».
- В цепочке методики роль Q&A — пауза/снятие возражений между этапами.

Допустимые значения «Тип блока»:
- Введение
- Концепция
- Методология
- Инструмент / практика
- Пример / кейс
- Демонстрация
- Задание / ДЗ
- Вопросы / ответы
- Орг. момент
- Итоги / резюме
