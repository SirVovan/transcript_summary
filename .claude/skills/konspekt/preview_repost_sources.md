# Реестр источников перезаливов (preview)

Владелец заливает ЧУЖИЕ видео на **свой** канал-ферму ради бесплатного
авто-транскрипта, складывая их в выделенные **dump-плейлисты**. На этом же канале
есть и собственный контент владельца, поэтому матчинг идёт **не по каналу целиком,
а по членству видео в dump-плейлистах**.

Признак перезалива (вычисляет `youtube_to_srt.py` при скачивании):

1. `channel_id` видео входит в список **каналов-ферм** ниже (перезалив физически
   всегда на канале владельца — чужой `channel_id` перезаливом быть не может).
2. И само видео входит в один из **dump-плейлистов** ниже.

Если оба условия выполнены — в шапку SRC пишется `# repost: true`, и preview-режим
(ШАГ 2.2, Ветка B) игнорирует фейковые метаданные YouTube. Видео с канала-фермы
**вне** dump-плейлистов считается собственным контентом владельца (метаданные
настоящие). Если членство не удалось проверить (сеть) — пишется `# repost: unknown`,
и preview задаёт владельцу один вопрос.

Матчинг — строго по стабильным id (`UC…` канал, `PL…` плейлист), не по именам.

## Каналы-фермы

- channel_id: UCxFSGyMfQL5PBJIAy_vs4Lg   # Владимир Купчинский

## Dump-плейлисты

- playlist_id: PLMOwD8l9FRPFjw4iLH-KriqyprpF1bqP2   # залив чужих файлов #1
- playlist_id: PLMOwD8l9FRPHFLw1NGcEPpDp-NebfmwR3   # залив чужих файлов #2

## Как добавить ещё

**Канал-ферма** (если завёл новый канал под залив):

```bash
yt-dlp --print channel_id --playlist-items 1 --skip-download --no-warnings "<URL канала или видео>"
```

Вернёт `UC…` — добавить строкой `- channel_id: UC… # имя` в раздел «Каналы-фермы».

**Dump-плейлист** — взять `list=PL…` из URL плейлиста и добавить строкой
`- playlist_id: PL… # комментарий` в раздел «Dump-плейлисты».

> Формат строки важен: парсер берёт только значения после `channel_id:` и
> `playlist_id:`. Не вписывай заглушки вида `channel_id: UC…` с настоящей длиной —
> используй `<...>` в примерах, иначе попадут в реестр.
