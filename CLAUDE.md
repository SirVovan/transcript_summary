# Konspekt Project

Этот проект обрабатывает транскрипты видеолекций в учебные материалы.

## Протокол «обнови хранилище»

В конце сессии — **только если была архитектурная эволюция** (новый слой/режим, изменение пайплайна, переписанное правило, новый компонент):

1. Создать запись `YYYY-MM-DD-{slug}.md` по шаблону существующих (frontmatter `archive: true` → шапка «АРХИВ» → разделы «Что изменилось» / «Почему так» / «Где менять»).
2. Добавить одну строку в соответствующий INDEX.

**Куда писать:**

- **Скилл `/konspekt`** (master / виджет / preview, профили, парсер, генератор виджета) — прямо в `docs/evolution/`, строка в `docs/evolution/INDEX.md`.
- **Ответвления (production-сервисы поверх скилла)** — в подпапку `docs/evolution/<project>/`, строка в `docs/evolution/<project>/INDEX.md`. Текущие подпапки:
  - `docs/evolution/tg-bot/` — Telegram-бот поверх режима `/konspekt preview` (с 2026-05-29).

Хранилище — **только в репо**, vault для ответвлений не используется.

Если эволюции не было — ничего обновлять не нужно. Применения скилла к конкретным лекциям (виджеты, патчи, обработанные транскрипты) — это продукты, в журнал не идут.

`docs/evolution/**` — постоянный архив. Не читать автоматически; обращаться только когда пользователь явно ссылается на конкретное событие или дату.

Ближайшие приоритеты на следующую сессию живут в `backlog.md`, раздел «Ближайшие приоритеты».

## Как работать

Когда пользователь даёт транскрипт или просит обработать его в мастер-MD, виджет или preview —
использовать скилл `/konspekt`. Он содержит полный пайплайн и все необходимые инструкции.

Режимы скилла:
- `/konspekt <путь>` — полный мастер-MD (основной режим, см. `SKILL.md`).
- `/konspekt — сделай виджет из <файл>` — виджет: Слой 2 + Слой 3 (см. `layer2_widget.md`, `layer3_recon.md`).
- `/konspekt preview <путь или YouTube-URL>` — предварительный обзор видео ~800–950 слов (см. `preview.md`).

Все рабочие файлы скилла находятся в `.claude/skills/konspekt/`.
Выходные файлы сохраняются в `transcripts/` (или в рабочей папке урока с префиксом `OUT_`).
