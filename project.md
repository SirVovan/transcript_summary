# project.md — Konspekt Project

## Что это

Двойной проект: инструмент для обработки транскриптов видеовыступлений в структурированные учебные материалы — и одновременно живой скилл, который дорабатывается и улучшается по ходу работы.

Получает на вход текстовый транскрипт (опционально — презентацию и/или скрины промптов) и за один проход выдаёт **мастер-MD**: единый структурированный конспект урока в голосе спикера. На основе мастер-MD по отдельной команде собирается интерактивный виджет. Параллельно архитектурная эволюция скилла фиксируется в `docs/evolution/`, чтобы каждая следующая сессия работала лучше предыдущей.

> Полный пайплайн, правила и шаблоны — в `.claude/skills/konspekt/SKILL.md` (**источник истины**). Этот файл — только высокоуровневый обзор.

## Для кого

Для студентов и учеников онлайн-курсов, которые хотят иметь удобные конспекты видеоуроков — без необходимости смотреть видео повторно.
Прежде всего — для обработки уроков курса «Вайбкодинг» (спикер Дмитрий Ледовских).

## Проблема

Видеолекции неудобно перечитывать и возвращаться к ним за конкретной мыслью. Транскрипты содержат шум и паразитные элементы. Вручную структурировать урок — долго. Этот проект автоматизирует весь цикл обработки.

## Основные функции

**Три режима скилла `/konspekt`:**

1. **Мастер-MD** (`/konspekt <путь>`) — основной режим. Транскрипт → единый структурированный конспект за один проход: главная мысль, сегментация по крупным смысловым блокам, текст в голосе спикера, навигационные карты, встроенные промпты.
2. **Виджет** (`/konspekt — сделай виджет из <файл>`) — интерактивная HTML-презентация мастер-MD: один экран = один смысловой блок, навигация по вкладкам, оживлённый первый экран (Слой 2 + Слой 3).
3. **Preview** (`/konspekt preview <путь или YouTube-URL>`) — текстовый предварительный обзор видео ~800–950 слов до полной обработки.

**Развитие скилла** (всё в `.claude/skills/konspekt/`):

- `SKILL.md` — методология, формат мастер-MD, самопроверка (источник истины пайплайна)
- `profile_*.md` — профили контента по типу выступления (лекция / custdev / встреча / конференция / база)
- `layer2_widget.md`, `layer3_recon.md` — правила сборки и оживления виджета
- `preview.md` — режим предварительного обзора
- `widget_generator.py`, `validate_widget.py`, `md_parser.py` — сборка и валидация виджета

Архитектурная эволюция скилла логируется в `docs/evolution/` (постоянный архив + INDEX).

## Страницы / экраны

- `transcripts/` — входящие транскрипты (.txt, .docx) и сопроводительные материалы (презентации, скрины промптов)
- `transcripts/[название]_мастер.md` — мастер-MD урока
- Виджет (HTML) — интерактивная презентация мастер-MD
- При работе в отдельной папке урока — выходные файлы с префиксом `OUT_`

## Чего НЕ будет (пока)

- Автоматической транскрибации аудио/видео — транскрипт подаётся вручную
- Веб-интерфейса или деплоя — всё работает локально через Claude Code
- Поддержки других языков, кроме русского
- Автоматической публикации или отправки файлов
