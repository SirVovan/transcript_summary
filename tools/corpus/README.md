# tools/corpus — экстракция корпуса для дообучения заголовков/сегментации

Скрипты вытаскивают из локальных транскриптов Claude Code (`~/.claude/projects/<...>/*.jsonl`)
материал для базы кейсов `docs/segment-headers-cases.md`. Все пишут в `.corpus-scratch/`
(gitignored). Запуск: `python tools/corpus/<script>.py`.

| Скрипт | Что делает |
|--------|-----------|
| `extract_user_replies.py` | Лента всех реплик пользователя по сессиям (первичный индекс правок — реплики короткие, в них суть). |
| `extract_timeline.py <id…>` | По id сессий: чередование реплик и строк-заголовков из ответов — видеть пары «было→стало» в контексте. |
| `score_principles.py` | Ранжирует сессии по объёму реплик о заголовках/принципах — искать глубокие «принципиальные» диалоги. |
| `extract_principles_context.py <id…>` | Полные реплики + заголовки-контекст по id (поиск по нескольким project-папкам). |

Принцип: детект правок — по **репликам пользователя** и по диффу артефакта-заголовков,
а не по ключевым словам (они дают плохой recall). Подробнее — `docs/segment-headers-analysis.md`.
