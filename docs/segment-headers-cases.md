# База кейсов: заголовки и границы сегментов

> **Назначение.** Корпус реальных правок `было → стало → нарушенное правило` для дообучения
> скилла `/konspekt` на этапе сегментации и создания заголовков (режим master, ШАГ 1.4).
> Это **evidence** — материал, из которого позже выводятся 4–6 повторяющихся паттернов и блок
> контраста для ШАГ 1.4. Контекст задачи — `docs/task-segmentation-headers-retraining.md`.
>
> **Как сюда попадают записи.** Автоматически: в конце master-сессии, где пользователь
> правил заголовки или границы сегментов, агент дописывает пары сюда (правило в `SKILL.md`,
> ШАГ 4). Можно дописать и вручную по команде «запиши в базу кейсов».
>
> **Когда накопится 4–6 кейсов на паттерн** — вынести паттерны и блок «было → стало» в точку
> применения (ШАГ 1.4) и обновить `docs/evolution/`.

## Коды паттернов

| Код | Паттерн ошибки |
|---|---|
| P1 | Назывной заголовок («Введение:…», «Демонстрация:…») вместо глагола процесса |
| P2 | Антитеза «не А, а Б» в заголовке |
| P3 | Принцип / лозунг в заголовке вместо глагола процесса |
| P4 | Размельчение сегментов (15+ на 90 мин) |
| P5 | Заголовок не про пользу читателю |
| P6 | Жирным весь заголовок вместо части до двоеточия |
