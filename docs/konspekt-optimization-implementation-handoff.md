---

## Подход к выполнению

**Subagent-driven** с явным указанием `model: "sonnet"` для каждого субагента:

1. Главный агент (Opus) выступает координатором: читает план, диспетчирует задачи, проверяет результат каждой между диспатчами.
2. Каждая задача = свежий субагент с `subagent_type: "general-purpose"` и `model: "sonnet"`.
3. Задачи Task 2, Task 4, Task 6 — относительно простые, идут быстро.
4. Задачи Task 3 (subagent_phase2.md) и Task 5 (brigadir.md) — большие, у каждой много шагов; на них уйдёт основная часть бюджета.
5. Task 1 (preprocessor.py head) — единственная с кодом и TDD-логикой.

**Использовать скилл:** `superpowers:subagent-driven-development` для координации.

---

## Ключевые ограничения (из плана раздел «Дисциплина бригадира»)

В этой сессии главный агент должен:
1. **Не использовать TodoWrite** для отслеживания задач плана. План сам по себе — это todo-list. Прогресс отмечается отметкой шагов `- [ ]` → `- [x]` прямо в файле плана (это требование скилла executing-plans/subagent-driven-development).
2. **Не запускать дополнительные deferred tools** без необходимости.
3. **Не делать тестовый прогон скилла** — это следующая сессия.
