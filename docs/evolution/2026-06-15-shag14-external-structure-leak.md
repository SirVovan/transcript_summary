# 2026-06-15 — ШАГ 1.4: «чужая структура — подсказка, не карта» + защёлка от перекомпенсации

Вторая интервенция в ШАГ 1.4 поверх [2026-06-11](2026-06-11-shag14-heading-checklist-and-self-check.md). После первой интервенции корпус `segment-headers-cases.md` прирос кодами P12 (ложное лицо в Q&A-заголовке), P13 (служебный жаргон скилла в заголовке), B6 (нарезка по слайдам) и анти-B6 перекомпенсацией (B5 — слил разнотемное ради числа). Свежий разбор (analysis, Часть 5) показал: это не отдельные баги, а варианты одного механизма.

## Что изменилось

В `SKILL.md` — 7 точечных правок (ШАГ 0 + ШАГ 1.4):

1. **ШАГ 0, презентация.** Убрана формулировка «структуру выступления (ориентир для сегментации)» — она сама индуцировала B6. Заменена: деление на разделы = подсказка к этапам, не готовая карта глав; по слайдам не сегментировать (ровные куски — признак ошибки); карта — по смысловым этапам метода (1.3).

2. **ШАГ 1.4, новый принцип «Чужая структура — подсказка, не карта».** Слайды презентации, фазовые ярлыки спикера и служебный словарь самого скилла («Замысел/Рамка/Резюме») — навигация говорящего/инструмента, не карта глав читателя; на карту 1:1 не переносить (фазу спикера по смыслу можно и разрезать, и слить).

3. **ШАГ 1.4, счёт → блок «Сигналы для перепроверки».** Сегмент < ~3 мин → тест на укрупнение (в Q&A оправдан, в лекции реже). Подозрительная ровность длительностей → пересборка карты от смысла, а не попарное слияние (разная адресация лечения для разных сигналов).

4. **ШАГ 1.4, «Защёлка от перекомпенсации»** в тесте на укрупнение. Инвариант: одна мысль / одно цельное действие = один сегмент; укрупнение ≠ слить разнотемное до целевого числа. Промпт — сигнал, не равенство (сегмент может держать несколько промптов одного действия — иначе конфликт с правилом «Вставка промптов»).

5. **ШАГ 1.4, заголовки — причина «технических» заголовков.** Назван механизм: агент списывает заголовок с поверхности транскрипта (что показывали на экране), а не формулирует пользу. Разворот: «что я отсюда возьму», а не «что тут показывали». Процессный глагол («ищем/собираем») — это и есть польза, его не трогать.

6. **ШАГ 1.4, чек-лист — пункт про краевые/служебные сегменты.** Вводный/итоговый/Q&A-пауза называть как средние: без описания формата, без жаргона методологии, без ложного лица; Q&A — именная группа «Пауза на вопросы — <суть>». «Этап N» — исключение. [P12, P13]

7. **ШАГ 1.4, ветка лекции-методологии.** Формат «Этап N — <действие>: <одна суть>», не перечисление всех инструментов внутри. [P8]

В `docs/segment-headers-analysis.md` дописана Часть 5 — пять системных закономерностей с привязкой к правкам.

## Почему так

Корень из интервенции 2026-06-11 («скилл оптимизирует под удобство пишущего, а не под понимание читателя») подтвердился и **расширился**. Все накопленные коды — варианты одной подмены: **агент берёт готовую внешнюю опору вместо смысловой карты читателя.** Опора бывает разной — слайды (B6), фазы спикера (B3/P1), собственный жаргон скилла (P13), число соседнего урока (анти-B6), ровность длительностей. Поэтому правки бьют не только по правилу, но и по **индуцирующим формулировкам** (ШАГ 0 буквально звал резать по презентации — тот же мета-дефект, что счётные якоря, снятые в июне).

Два наблюдения определили форму правок:
- **Перекомпенсация.** Кейс У27 — прямое evidence: выучив одно правило (B6), агент качнулся в противоположный полюс (B5). Маятник лечится не парой противонаправленных запретов, а одним положительным инвариантом + защёлкой.
- **Краевые сегменты — отдельный очаг.** Содержательные средние почти не правятся; сбои кучкуются на границах карты (вводный/итоговый/Q&A), где рамка «польза читателю» у агента отключается.

Формулировки прошли два круга критической самопроверки: сняты противоречие «один промпт = один сегмент» ↔ правило о нескольких промптах; конфликт «убрать действия из заголовка» ↔ требование процессного глагола; перекомпенсация в самой Правке A (не выбрасывать деление на разделы вместе со слайдовой дробностью); абсолютизм «в лекции коротких почти нет».
