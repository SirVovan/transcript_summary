# 2026-05-04 — Слой 1: разделение вычисления и представления

## Что изменилось

Пайплайн перестроен на два слоя:

- **СЛОЙ 1: Вычисление** → производит единственный артефакт `мастер.md` (структура + текст).
- **СЛОЙ 2: Представление** → механически рендерит мастер-MD в форматы (на этом этапе отложен).

Внутри Слоя 1 — четырёхступенчатый пайплайн:

1. ШАГ 0: Предобработка. Если >25K токенов — нарезка скриптом `preprocessor.py`.
2. ШАГ 1а: Сегментация + самопроверка по 4 критериям.
3. ШАГ 1б: Параллельные субагенты — по одному на сегмент (Карта + Текст).
4. ШАГ 1в: Бригадир: верификация, гармонизация, переходы, сборка.

## Почему так

**Один артефакт вместо XLSX/DOCX/HTML.** Карта и текст рождаются в одном MD-файле — нет дублирующих чтений транскрипта, нет переплетения «логика и формат».

**Порог 25K токенов = ~2 часа видео.** Эмпирически выше этого Claude в одном контексте теряет качество к концу. До порога — без нарезки.

**Гибридная нарезка (скрипт + LLM), не тупая по размеру.** `preprocessor.py` накапливает токены, при ~15–18K вырезает окно ±10 минут, лёгкий LLM-вызов ищет в окне смысловую границу. Если уверен — режет молча, иначе пауза с вопросом пользователю. Альтернатива «резать по размеру» отвергнута: получали бы рваный контент.

**Субагент на сегмент, не один Claude на весь транскрипт.** Один Claude на 36K транскрипта + инструкции + текст = ~60K контекста, качество падает. Субагент получает только свой сегмент (~2–5K) + навигационную карту (~1–2K) + ToV (~200 ток) — контекст маленький, качество стабильное.

**ToV-спецификация гибридная.** Базовая часть фиксированная (первое лицо, живая речь, без академизма), динамическая — Claude читает первые ~2–3K токенов и выделяет обороты, темп, фирменные фразы конкретного спикера. Субагенты пишут в его голосе, а не абстрактно.

**Бригадир — единственный верификатор.** Проверяет, все ли тезисы карты раскрыты в тексте, гармонизирует стиль, пишет переходы. Проблема → переделка субагента; второй сбой → метка ⚠️ и продолжение.
