# 2026-05-15 — Нарезка по времени + унификация пайплайна

## Что изменилось

- **Нарезка по времени, не по токенам.** `preprocessor.py` переключён на тайминг:
  - `CHUNK_DURATION_SEC = 3600` (60 мин) — основной режим, если в транскрипте есть тайминг.
  - `CHUNK_SIZE_TOKENS = 12_000` (~60 мин в токенах) — фоллбэк без тайминга.
  - `windows()` ставит точки реза через каждые 60 мин по таймштампам, в токен-режиме — по накоплению.
  - `info()` показывает длительность и подпись режима (`[тайминг-режим]` / `[токен-режим]`).
- **Лёгкий режим удалён.** Единый пайплайн для всех транскриптов: сегментация всегда делегируется Фазе 1, бригадир всегда получает черновые карты Фазы 1, занимается только глобальным обзором → чистовой картой → Фазой 2 → сборкой.

## Почему так

**Чанки 75–80 мин были слишком большими.** При `CHUNK_SIZE = 16_000` обработка одного чанка занимала слишком долго. Тайминг в транскрипте уже есть — логично резать по нему. 60-минутные чанки дают предсказуемые границы, привязанные к смысловой структуре материала, а не к произвольной токенной отметке.

**Лёгкий режим занимал контекстное окно бригадира.** При транскриптах ≤ 25K Claude делал всё сам (сегментация + текст + реконструкция), не оставляя места для качественной работы над логикой и траекторией. Унификация: бригадир никогда не сегментирует. Это закрывает класс багов «при коротких видео бригадир ведёт себя иначе» и снимает необходимость поддерживать две ветки кода.

## Где менять

- `preprocessor.py` — константы, `has_timestamps()`, `info()`, `windows()`.
- `SKILL.md` — убран «Лёгкий режим», единый пайплайн, обновлены диаграмма и таблица.
- `brigadir.md` — раздел «Роль»: убрана ссылка на лёгкий режим.
