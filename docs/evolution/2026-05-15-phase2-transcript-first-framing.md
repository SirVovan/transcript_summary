# 2026-05-15 (вечер) — Корневая правка постановки задачи Фазы 2: транскрипт первичен

## Что изменилось

Перевёрнут фрейм задачи субагента Фазы 2. Источник истины — транскрипт, а не Карта.

- **Текст** = очищенный транскрипт, сохраняющий голос автора. 70–90% объёма.
- **Карта** = извлечение оглавления из готового Текста, не задание для него.
- **Ключевая мысль** = итог после Карты.

Порядок работы субагента: транскрипт → Текст → Карта → Ключевая мысль.

Бригадир тоже переориентирован: источник истины при верификации — транскрипт, не чистовая карта. Три шага: чтение блока `### Самопроверка` субагента → выборочная сверка с транскриптом → запрос переделки при необходимости. Блоки `### Самопроверка` вырезаются из финального мастер-MD.

## Почему так

На реальном прогоне (9 сегментов, ~95 мин) 4 из 9 сегментов имели дефект: субагент Фазы 2 писал кратким содержанием вместо раскрытого конспекта. Текст выходил сопоставимым по объёму с Картой (~1× вместо целевых 2–3×).

Первая попытка лечения — добавить самопроверку «раскрытости буллетов Карты в Тексте». Но это лечение симптома. Корень: задача субагенту была поставлена с ног на голову — Карта подавалась как первичная, Текст как её развёртывание. При таком фрейме субагент сжимал транскрипт в тезисы (Карта), а потом «разворачивал обратно» — транскрипт фактически выпадал из процесса.

Самопроверка на «раскрытость» не убирает причину. Перевёрнутый фрейм снимает проблему на уровне задачи — самопроверка становится проще и честнее («сохранил ли я голос автора», «вырезал ли только шум»).

## Где менять

- `subagent_phase2.md` — переписан целиком: новый раздел «Принцип постановки задачи» (транскрипт = единственный источник), перестановка порядка процесса и выводных блоков, таблица «убираем шум / сохраняем стилистику», обязательный `### Самопроверка` (содержание / стилистика / объём), запрет «не пиши Карту первой».
- `brigadir.md` — раздел «Верификация текста» переписан, добавлен раздел «Очистка перед сохранением» (вырезание `### Самопроверка`).
