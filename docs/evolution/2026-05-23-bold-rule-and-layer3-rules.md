# 2026-05-23 — Правило жирного качественное, технический минимум реконструкции, правила Слоя 3

## Что изменилось

### Правило жирного: с количественного на качественное

Старое правило «1–2 коротких якоря по 1–3 слова на абзац» заменено на качественное.

**Новое правило в `SKILL.md`, раздел «Навигация в Тексте»:** жирное = **сжатая формулировка ключевой мысли абзаца / значения / буллета**. Длина определяется полнотой смысла, не лимитом (часто 4–8 слов). Главный тест: прочитать только жирное во всём сегменте сверху вниз — складывается ли канва смыслов? Если разрозненные слова — выделение «по форме правильное», но не работает.

Структурные пометки (`**Ключевая мысль:**`, `**Тип:**`, `**Кейс 1:**`, ярлыки в `> ...`-блоках) остаются жирными для фокусировки, в счёт лимита абзаца не идут. В списках «заголовок — раскрытие» заголовок до тире/двоеточия жирный.

### Технический минимум Логической реконструкции

Раздел `## Логическая реконструкция` в мастер-MD = **только** цитата `> **Главная идея:**` (дословная копия из шапки) + таблица сегментов. Прозы нет — она ушла в работу агента как «мысленная сборка сквозной цепочки И→М→Д».

Метки `(И)/(М)/(Д)` в Карте — **внутренний инструмент агента**, в финальный файл не пишутся.

### Слой 3: правило «дуга → реконструкция», не пересказ

В `layer3_recon.md` (раздел «Левая колонка»):

- **Иерархия источников** для левой колонки: Главная мысль шапки → Ключевые мысли → Карта → Текст → Таблица.
- **Принцип:** левая колонка формулирует риторическую дугу всего выступления, опираясь на Главную мысль шапки как фундамент. Это смысловое разворачивание Главной мысли через материал сегментов — не пересказ сегментов абзац-за-абзацем.
- **Антипаттерны:** пересказ сегментов по порядку (признак — «можно подписать номер сегмента, и совпадёт»), общая формула без конкретики, потеря Главной мысли как ведущей нити, «потеря поворота» (если в Главной мысли есть «но» — должен быть отдельный абзац разворота), литературоведческий разбор (с примерами оборотов).
- **Цель левой колонки:** взгляд на урок сверху для читателя. Не литературоведческий разбор «как устроено выступление», а карта урока — что хочет донести автор.
- **Простой разговорный язык** без оборотов «риторическая дуга», «фундамент держит», «глубинное зачем». Тест: прочитать абзац вслух — звучит как человек объясняет другу, или как преподаватель риторики? Если второе — переписать.

## Почему так

**Количественное правило ломалось на смысле.** «1–2 якоря, 1–3 слова» — самопротиворечиво: «якорь — смысловая опора» и «1–3 слова» — две разные модели. Пара слов передаёт тему («о чём абзац»), но не смысл («что в абзаце сказано»). На мастер-MD М2-У10-1 получились слова-метки («23 раза», «билборд», «Telegram»), не складывающиеся в канву.

**Качественное правило — плата за результат.** Когда правило задаёт форму — оно быстрое в применении, но ломается на смысле. Когда задаёт смысл — оно работает, но требует мысленной работы на каждом абзаце. Это не баг.

**Реконструкция = технический минимум.** Цитата + таблица. Проза ушла в голову агента и в Слой 3, где она пишется уже для читателя, не как саммари таблицы.

**Слой 3 после удаления прозы из мастер-MD рисковал деградировать в плоский пересказ.** Без явного правила «дуга, не пересказ» агент скатывался в «абзац за сегмент». Левая колонка для М2-У10-1 переписывалась трижды: пересказ → литературоведческий разбор «риторическая дуга, фундамент держит» → простой язык. После третьей версии правила добавлены в `layer3_recon.md`.

**Структурные пометки и навигационные якоря — две функции.** Структурная пометка (`**Кейс 1:**`) помогает глазу прыгать по структуре файла. Навигационный якорь (`**Mini App = обычный сайт в новой обёртке**`) помогает понять смысл. Не складываются в один счётчик.
