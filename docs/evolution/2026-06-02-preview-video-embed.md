# 2026-06-02 — Ссылка на источник и встроенный плеер в обзоре `preview`

## Что изменилось

В обзоре режима `/konspekt preview` теперь, если видео скачивалось с YouTube, в шапку выводится **ссылка на источник** и **встроенный плеер** (Obsidian рендерит его из `![](url)`). Зритель открывает обзор и сразу может запустить видео в самом файле.

Единственный источник истины об URL — **строка-метка в начале `.srt`**. Скрипт пишет её при скачивании; preview-режим читает её при любом входе. Так YouTube-вход текущей сессии и повторный обзор ранее скачанного локального файла одинаково получают ссылку.

**Правки в двух местах:**

1. **[youtube_to_srt.py](../../.claude/skills/konspekt/youtube_to_srt.py):**
   - Новая `_canonical_youtube_url(url)` — извлекает 11-символьный video ID из `watch?v=` / `youtu.be/` / `embed/` / `shorts/`, отбрасывает лишние `&list=`/`&t=`, собирает канонический `https://www.youtube.com/watch?v=<ID>`. Если ID не распознан — возвращает исходный URL.
   - В `download_subtitles` перед записью файла в начало содержимого дописывается строка-метка `# source: <канонический URL>` + пустая строка. CLI и коды выхода не тронуты.

2. **[preview.md](../../.claude/skills/konspekt/preview.md):**
   - **ШАГ 0.3 (новый)** — после чтения транскрипта проверять первую строку на `# source: <URL>`, запоминать URL для шапки; саму метку в обзор не переносить. Прежний 0.3 «Язык вывода» сдвинут в 0.4.
   - **ШАГ 2.2** — в шаблон шапки под строкой «Длительность · Спикер · Формат» добавлены `**Источник:** [YouTube](<URL>)` и `![](<URL>)`. Под шаблоном — оговорка: блок выводится только при известном URL, иначе обе строки опускаются; alt у плеера пустой.
   - **Граничные случаи** — строка про локальный файл без метки `# source:` (блок видео не выводится).

## Почему так

**Почему метка в `.srt`, а не «запомнить URL из аргумента».** Для YouTube-входа Claude знает URL прямо в сессии, но обзор пишется из скачанного файла, и при повторном обзоре того же `.srt` позже URL был бы потерян. Метка в файле делает ссылку переносимой: один источник истины, который Claude и так читает целиком в ШАГ 0.

**Почему формат `# source:` безопасен.** Блок без таймстампа `parse_srt` пропускает (проверено), так что повторная переразбивка файла не ломается. Для Claude в preview-режиме это просто первая строка текста — легко распознать и исключить из содержания.

**Почему URL нормализуется.** Пользователь может подать `youtu.be/…?t=42` или `watch?v=…&list=…`. Лишние параметры мешают встраиванию плеера в Obsidian. Канонический `watch?v=<ID>` рендерится надёжно.

**Почему плеер `![](url)` с пустым alt + отдельная ссылка `[YouTube](url)`.** `![](url)` — нативный способ Obsidian встроить плеер; пустой alt исключает путаницу с указанием размера (`![300](url)`). В вьюверах без поддержки встроенного плеера `![]` даст битую картинку, но рядом стоит рабочая текстовая ссылка-источник — доступ к видео не теряется нигде.

**Почему тайминги НЕ сделаны кликабельными.** Obsidian встроенным плеером по ссылкам не управляет — кликабельный таймкод открывал бы видео на моменте только во внешнем браузере/приложении, а в файле плодил бы шум вида `[(12:34)](url)` по всему обзору. Решено оставить тайминги текстом (см. правило 2.4).

## Где менять (применённые правки)

- `.claude/skills/konspekt/youtube_to_srt.py` — `_canonical_youtube_url` + запись метки `# source:` в `download_subtitles`.
- `.claude/skills/konspekt/preview.md` — ШАГ 0.3 (чтение метки), 2.2 (блок в шапке + оговорка), граничный случай.

## Что осталось висеть

- **Обзоры по локальным `.srt` без метки** (`.txt`/`.md`, файлы, скачанные старой версией скрипта) идут без блока видео — задним числом метку не дописываем.
- **Не-YouTube источники** (Vimeo, локальное видео) пока не поддержаны: метка и нормализация заточены под YouTube. При необходимости — расширять отдельно.
