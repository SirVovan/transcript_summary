# 2026-05-23 — Оптимизация SKILL.md: выборочный серийный контекст + стереотипы блоков + карта выделений

## Что изменилось

Три правки в `.claude/skills/konspekt/SKILL.md`, дающие постоянный эффект на каждой будущей сессии `/konspekt`. Изначально план оптимизации содержал четыре пункта (C, A, D, B); реализованы **C, A, D**, пункт **B (сжать SKILL.md)** отложен.

### C. Серийный контекст — читать выборочно

**Где:** ШАГ 0, пункт 1 «Серийный контекст».

До правки: при обнаружении `*_мастер.md` той же серии — прочитать **целиком**. На длинных сериях (Ледовских — десятки уроков, каждый мастер-MD ~10–15K токенов) — десятки тысяч входных токенов на сессию ради калибровки масштаба.

После: читать только **шапку + Карты + Ключевые мысли** последних 2–3 уроков. Полные Тексты — только при конкретном вопросе (например, «как спикер раскрывал термин X ранее»).

**Эффект:** до 30K входных токенов экономии на длинных сериях. Самая большая системная правка по токенам.

### A. Стереотипы для типовых блоков

**Где:** ШАГ 2, раздел «Навигация в Тексте» → новый подраздел «Стереотипы для типовых блоков».

Введены шаблонные правила жирного для повторяющихся структур:

- `> **Ключевая идея:** ...` / `> **Принцип:** ...` / `> **Методология:** ...` → первая основная фраза блока жирная как сжатая мысль; пояснение без жирного.
- `> **Метафора:** ...` → жирной идёт сама формулировка («A — это как B»).
- Подзаголовки `#### Различие N — параметр` / `#### Кейс N — название` → заголовок работает как жирный навигационный якорь; в первом содержательном абзаце под ним — обычное правило сжатой мысли.
- Блок `> **Кейс N — название:** короткая формулировка` → структурная пометка жирная по умолчанию + одно дополнительное выделение в формулировке (если длиннее 5–6 слов).

**Эффект:** ~10–15 решений «с нуля» на каждом мастер-MD заменены на шаблон.

### D. Микро-шаг «карта выделений» в ШАГ 2

**Где:** ШАГ 2, раздел «Шаблон сегмента».

До правки: на длинных перегенерациях главный источник откатов — перефразирование оригинального текста спикера под желаемое выделение. Цикл «писать → передумал → вернуть как было».

После: перед записью каждого сегмента — короткая мысленная карта выделений. Сначала формулируешь «что главное в этом абзаце» (одна-две фразы), затем пишешь блок целиком, расставляя жирное по этой карте. Карта не пишется в чат и не сохраняется — внутренний микрошаг, как и сквозная цепочка (И)→(М)→(Д).

**Эффект:** меньше переделок «писать → отменять → переписывать» внутри ШАГ 2.

## Почему так

Ретроспектива после долгой перегенерации мастер-MD М2-У10-1 (правка правила жирного) показала два места торможения: большой объём мысленных решений на каждый абзац и дублирующиеся разделы в SKILL.md. C/A/D адресуют первое; B (сжатие SKILL.md) откладывалось до 2–3 сессий применения нового правила жирного — чтобы было видно, какие куски устаканились.
