# 2026-05-25 — Блок «Замысел и маршрут» в мастер-MD: маршрут до сегментации

## Что изменилось

В мастер-MD появился новый раздел `## Замысел и маршрут`, который ставится сразу после шапки. Раздел условный — пишется только когда у материала есть **единая нить** (методология / развивающаяся мысль / разбор с аркой). Тест на нить: «можешь сформулировать в 4–8 пунктах, что автор делает по порядку?»

Раздел состоит из двух частей:
- **Проза «взгляд сверху»** (4–6 абзацев) — о чём урок, что автор доносит, какая логика.
- **Опорная структура** — список из 4–8 пунктов. Форма зависит от типа материала: лестница этапов (методология) / тезисы (лекция-идея) / опорные точки (разбор с аркой). Набор форм не заморожен — парсер не различает.

**Изменилась последовательность ШАГ 1:**
- 1.2 — главная мысль (как было).
- **Новый 1.3 — «Замысел и маршрут»**: до сегментации формулируется опорная структура. Прозу здесь НЕ пишем.
- 1.4 (бывший 1.3) — сегментация. Если опорная структура есть — сегменты = её пункты, заголовки наследуют формулировки. Если нет — старая логика от главной мысли.

**Проза «взгляд сверху» дописывается в конце ШАГ 2**, когда все сегменты уже написаны. Агент возвращается к началу мастер-MD, имея перед глазами всю структуру — пишет ретроспективно, как раньше делал Слой 3.

**Слой 3 (`layer3_recon.md`) стал бимодальным:**
- Режим А — блок есть в мастер-MD: Слой 3 копирует прозу и опорную структуру дословно, не сочиняет.
- Режим Б — блока нет (старые мастер-MD): старая логика сочинения как fallback.

SVG-схема и правая колонка артефактов не тронуты — работают как раньше.

**Парсер (`md_parser.py`)** распознаёт новый раздел и отдаёт `data['route'] = {'prose': <html>, 'structure': <html>}` или `None` если блока нет. Маркер опорной структуры — любая строка `**Label:**` (имя не зафиксировано, парсер гибкий).

## Почему так

**Симптом, который не уходил.** При обработке лекций пользователь регулярно переименовывал заголовки сегментов руками — они выходили разрозненными, без преемственности, не складывались в маршрут. Это повторялось несмотря на правило из `profile_lecture.md` «сегменты = ШАГИ единого процесса».

**Причина.** Сейчас в скилле порядок такой: сегментируем по сменам тем → потом видим, что у автора есть замысел → пытаемся натянуть на сегменты нумерацию «Этап N». Сегменты нарезаны по одной логике (тематические границы), названия даются по другой (этапы замысла). Натяжка видна — куски не складываются в маршрут.

**Решение.** Маршрут должен **рождаться до** сегментации и **диктовать** её, а не подбираться задним числом. Тогда заголовки сегментов не «подгоняются под этапы» — они **и есть** этапы, выведенные из ранее сформулированной опорной структуры.

**Где живёт маршрут.** До этой правки «взгляд сверху» сочинял Слой 3 (виджет) — у него перед глазами уже готовый мастер-MD, поэтому проза получалась хорошо. Но это «реконструкция задним числом», а не «изначальный замысел». Переносим источник правды в мастер-MD: маршрут диктует структуру, Слой 3 теперь только верстает готовое.

**Почему проза дописывается в конце ШАГ 2, а не в 1.3.** Если писать прозу до сегментации, агент пишет «вперёд» (ещё не нарезал, ещё не разобрал) — качество страдает. Если только опорную структуру в 1.3, а прозу в конце — агент пишет ретроспективно с полным контекстом, условия совпадают с тем, как сейчас сочиняет Слой 3. Это решение возникло в обсуждении: пользователь заметил риск потери качества прозы, разнесли по двум моментам.

**Условность блока — гибкая.** Изначальный план был «всегда блок для лекций-методологий». В обсуждении пришли к гибкому подходу: блок ставится, когда есть единая нить **любой формы**, не обязательно методология. Тесты, идеи, разборы — все валидны, форма опорной структуры адаптируется. Набор форм не замораживается — пополняется по мере появления новых типов лекций.

**Предыстория обсуждения.** Идея возникла в диалоге про У12, но та сессия упёрлась в перегруз контекста до того, как успели реализовать. Дизайн вынесли в `docs/design_route_block.md` как черновик-брейнсторм. В сессии 2026-05-25 продолжили: пять разделов дизайна (условность, парсер, Слой 3, методология ШАГ 1, миграция), оформление спеки, написание плана, исполнение Codex'ом под ревью Opus. Старые мастер-MD не трогаем — Слой 3 для них работает в режиме Б (fallback).

## Что осталось висеть

- **Контрольный прогон на свежем транскрипте лекции-методологии.** Критерий приёма — заголовки сегментов в новом мастер-MD складываются в маршрут без ручных правок пользователя. Если правки остаются — возвращаемся к спеке и уточняем формулировку под-этапа 1.3 или примеры теста на нить.
- **Имя маркера опорной структуры.** Парсер принимает любой `**Label:**` (`**Этапы:**` / `**Тезисы:**` / `**Опорные точки:**` — по форме). Открытый вопрос: фиксировать единое имя или оставить вариативным. Решение по итогам нескольких прогонов разных типов лекций.
- **Опциональная миграция старых мастер-MD.** Дописать блок задним числом в накопленные файлы серии Ледовских (У1–У12) — отдельная кампания, не привязана к этому релизу. Пока работает Режим Б (сочинение Слоем 3 как раньше).
