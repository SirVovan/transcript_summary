# 2026-05-21 — Слой 3: кастомный экран реконструкции виджета

## Что изменилось

Появился Слой 3 — кастомизация экрана `## Логическая реконструкция` виджета поверх готового HTML патч-скриптом. Парсер не трогается, кастомизация — post-processing патчем поверх готового виджета: адресная замена внутри `var BODY = {...}` и `var RIGHT = {...}` по ключу `"00"`.

### Принципы кастомного экрана

- **Левая колонка** — короткие абзацы прозой (1 абзац = 1 мысль) + опциональная **SVG-схема** (если у лекции есть операциональная схема — цепочка артефактов, параллели, цикл, иерархия; иначе не делать) + блок «Главная идея» в конце.
- **Правая колонка** — «артефакты урока»: секции с цветными карточками (Файлы / Промпты / Лайфхаки / Ссылки / Домашка). Состав секций под содержание лекции, не догма.
- **Раскрывающиеся `<details>` для промптов** — заголовок + краткое описание видны всегда, по клику разворачивается дословный текст с кнопкой «копировать». Нативно, без JS; стрелка `▶ → ▼` через scoped CSS на `[open]`.
- **Кликабельные `↗`** — переходят к нужному сегменту через готовую `goTo()` движка. Правило: если все элементы секции про один сегмент — стрелка на заголовке; если разные — у каждого элемента отдельно.

## Почему так

Из коробки экран реконструкции — кирпич прозы слева + пустая колонка справа (`<div class="insights"></div>` в `widget_generator.py:446`). Не работает как «мгновенная картина видео».

**Эволюция решения по ходу сессии — 6 итераций:**

1. ASCII-схема в `<pre>` — кириллица + псевдографика в Manrope рассыпались в узкой колонке. Перешли на SVG.
2. Карточки сегментов справа («1 — ТЗ как чертёж») — пользователь забраковал как «фразы выглядят оторванными, выдернутыми». Поняли: правая колонка не должна дублировать левую, она должна быть другим срезом материала.
3. **Артефакты урока** вместо карточек сегментов — операциональный список (что физически появится в проекте). Заработало.
4. SVG вместо ASCII — пользователь оценил как «намного интереснее».
5. Раскрывающиеся промпты через `<details>/<summary>`.
6. Кликабельные `↗` — сначала групповые на заголовках секций, потом индивидуальные (когда секция содержит привязки к разным сегментам).

**Ключевые уроки:**

- **Жанр карточек справа важнее их содержания.** «Карточка по сегменту» = бирка к бирке. «Карточка по артефакту» = инвентарь. Тот же визуальный формат, разный жанр восприятия.
- **`<details>` достаточно для раскрытий.** JS не нужен.
- **`event.stopPropagation()` критично для вложенных кликов.** Стрелка `↗` внутри `<details>` обязана останавливать всплытие, иначе клик разворачивает блок, а не идёт в сегмент.
- **Самопроверка перед отдачей.** В первой версии `patch_recon_m2u7.py` regex нашла первое `"00":`, но это оказался `RIGHT`, не `BODY` — проза и карточки поменялись местами. Исправил адресной заменой внутри явно найденного блока.

### Что НЕ автоматизируется

- Конкретный текст прозы — это смысл, не форма.
- Конкретный SVG — творческое решение под лекцию. Можно дать палитру типовых форм как ориентир, но генератор «автосхемы из мастер-MD» — путь к плохим схемам.
- Конкретные привязки `goto_id` — знание о структуре урока.

### Шаблон, не библиотека

Patch-скрипты эфемерны (один на лекцию). Каждый patch самодостаточен; импорт лишняя сложность для одноразового файла. Охранный запуск через подсчёт `# TODO` в исходнике — один централизованный гейт вместо разрозненных `NotImplementedError` в каждой заглушке.
