# 2026-05-15 (ночь) — Самопроверки бригадира #1, #2, #4 с анти-саботажным форматом

## Что изменилось

Добавлены три явные самопроверки бригадира на ключевых этапах пайплайна. Единый шаблон блока: `Что проверял / Находки / Действие / Итог`. Поле «Что проверял» обязано содержать **конкретные единицы** (пары сегментов, номера, цитаты), а не «всю карту». «Без находок» допустимо только при конкретно перечисленных проверенных единицах.

- **№1 (после Фазы 1, перед чистовой картой)** — взгляд читателя: тема сегмента называется одним словом? Два смысловых блока в одном сегменте? Соседние пары об одном (→ слияние)? Цепочка 3+ коротких = искусственное дробление? Финальный фильтр поверх инженерных критериев.
- **№2 (после чистовой карты, перед Фазой 2)** — карта целиком: заголовки подряд = логичное оглавление? Неконтактные повторы (сег. 1 и 7 об одном)? Темы из черновых карт Фазы 1 не выброшены при гармонизации? Крайний дисбаланс объёмов (порог 5×)?
- **№4 (после сборки мастер-MD, перед сохранением)** — финальный гейт: цельная история, нет повторов в соседних сегментах, нет провалов, переходы соответствуют содержанию, траектория/реконструкция опираются на реальное содержание.

Самопроверка #5 (Логическая реконструкция) НЕ добавлена — заменена усиленной инструкцией «Принцип абзаца» в `## Логическая реконструкция` («этот абзац — про риторику всего выступления одной мыслью, не саммари таблицы»).

## Почему так

**Главное ограничение — исключить саботаж.** LLM умеет штамповать `✓` без реальной работы. Анти-саботажный формат с обязательными конкретными единицами и осмысленным полем «Что проверял» делает фейковый «всё ОК» невозможным без проявленных конкретных проверок.

**Гейт после сборки (№4) — почти бесплатный.** Мастер-MD уже в контексте бригадира после сборки → input бесплатен. Платится только output блока (~1–3K токенов). На 5-часовом выступлении — <$0.05.

**№5 заменена «Принципом абзаца», потому что самопроверка-гейт — симптоматическое лечение.** Корневая правка — при написании, а не проверка постфактум. Атакует проблему («бригадир пишет проза-саммари таблицы») на этапе её зарождения, не тратит токены на output блока проверки.
