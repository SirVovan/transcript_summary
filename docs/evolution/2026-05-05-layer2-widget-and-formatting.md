# 2026-05-05 (вечер) — Слой 2: виджет + правила форматирования мастер-MD

## Что изменилось

### Слой 2: виджет из мастер-MD

Реализован Слой 2 — механическая конвертация мастер-MD в HTML-виджет без редакции контента.

Архитектура: Claude пишет компактный JSON (~2–3K токенов), `widget_generator.py` собирает из него HTML (~15–20K). Структура виджета: левая колонка = Текст, правая = Карта (буллеты как insight-карточки), один экран = один сегмент, Реконструкция = первый экран (сегмент `00`). Спецэлементы: `pr-block` (промпт + кнопка копирования), `cycle` (диаграмма шагов).

Цвета по риторической роли: открытие/введение → синий (concept), инструктаж/метод → зелёный (method), демонстрация/практика → оранжевый (demo).

### Форматирование мастер-MD

Введены правила выделений и спецблоков, чтобы Текст и Карта были одинаково богаты:

- **Ключевая мысль** — 1–2 предложения перед Картой каждого сегмента.
- **Жирный текст** — термины при первом упоминании, главная мысль абзаца. Максимум 1–2 выделения на абзац.
- **Спецблоки** — `> **Лайфхак:**`, `> **Важно:**`, `> **Демонстрация:**`. Только если материал явно есть в транскрипте.
- **Карта → Текст** — каждый буллет Карты содержательно раскрыт в Тексте. Требование на входе субагенту, не только контроль на выходе.

## Почему так

**JSON-промежуточный слой, а не прямая генерация HTML.** Claude не должен генерить HTML напрямую — это опасно (XSS-сюрпризы, поломки разметки) и раздувает контекст. JSON компактный, генерится дёшево; HTML собирается детерминированным Python-кодом.

**Цвета по риторической роли, а не по теме.** Виджет читается как «карта смены режимов автора», а не как тематический указатель. Концепт/метод/демо — три универсальные функции, которые любой обучающий материал использует.

**Форматирование как правила на входе субагентам, не постфактум-форматирование бригадиром.** После первого прогона Текст выходил сплошным нарративом, спецблоки не выделялись, Карта оказывалась богаче Текста. Постфактум-форматирование = дополнительная нагрузка на бригадира; правила на входе субагентам применяются при написании и обходятся дешевле.
