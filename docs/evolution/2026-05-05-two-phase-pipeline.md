# 2026-05-05 — Двухфазный пайплайн: субагент на чанк, бригадир между фазами

## Что изменилось

После первого реального прогона Слоя 1 пайплайн переработан:

- **Субагент на чанк (~15–18K токенов), а не на сегмент.** Нагрузка между параллельными агентами стала предсказуемой.
- **Две фазы вместо одной:**
  - **Фаза 1 — Черновая сегментация.** Субагент получает чанк → разбивает на сегменты с метаданными. Текст не пишет.
  - **Глобальный обзор бригадира (между фазами).** Получает черновые карты всех чанков → чистовая карта всего выступления.
  - **Фаза 2 — Написание текста.** Субагент получает чистовую карту + ToV + сегмент + кусок транскрипта. Пишет Карту + Текст.
- **Лёгкий режим (≤ 25K токенов).** Короткие транскрипты — Claude делает всё сам, без субагентов.
- **Логическая реконструкция** — новый раздел перед сегментами: абзац прозы (аргументация выступления) + таблица (сегмент → роль → ход автора).

## Почему так

На реальном прогоне вскрылись два дефекта старой схемы «субагент на сегмент»:

- **Неравномерная нагрузка.** Сегменты бывают от 5 до 40 минут — часть субагентов простаивает, часть тонет, качество прыгает.
- **Некачественная сегментация на первом проходе.** Q&A-блоки склеивались с лекционным контентом, сегменты получались смешанные.

**Чанки одинакового размера** решают первое: режутся до сегментации, по размеру, без знания структуры. Альтернатива «группировка сегментов в пакеты одинакового размера» отвергнута: требует сначала отсегментировать весь транскрипт, а сегментация и была проблемой.

**Бригадир между фазами, не после.** Если бы он работал после Фазы 2 — при изменении сегментации пришлось бы переписывать уже готовый текст. Глобальный обзор фиксирует структуру до того, как субагенты вложат время в текст. Бригадир проверяет три критерия: единство риторической функции (смешанный тег = разбивка), сигналы смены режима автора, логическая связность («ответ на один вопрос „почему здесь?“»).

**Лёгкий режим.** Для коротких транскриптов накладные расходы субагентов не оправданы — те же критерии, тот же формат, один контекст.
