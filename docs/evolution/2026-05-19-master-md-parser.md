# 2026-05-19 — Парсер мастер-MD: ручная сборка JSON для виджета убрана

## Что изменилось

`python widget_generator.py master.md` → HTML напрямую. Мастер-MD стал единственным источником правды для виджета.

Промежуточный JSON оставлен резервным режимом (для тонких правок виджета без правки MD). Диспетчер по расширению в `widget_generator.py`: `.md` → новый парсер, `.json` → как раньше.

Парсер реализован в `md_parser.py` как набор чистых функций: `_split_sections`, `_parse_meta`, `_apply_inline`, `_label_color`, `_render_blockquote`, `_render_prompt`, `_parse_text`, `_parse_map`, `_parse_segment`, `_parse_reconstruction`.

## Почему так

Слой 2 (виджет) собирался в два шага: автор вручную переносит содержание мастер-MD в JSON (~15 минут на виджет, с риском пропустить жирное или перепутать метку блока), потом `widget_generator.py JSON → HTML`. Промежуточный JSON был лишним «переводчиком»: любая правка мастер-MD молча устаревала виджет, ошибки переноса не ловились.

Контроль результата: эталонный мастер-MD прогнан через парсер, dict побайтово сравнён с эталонным JSON — meta совпадает, проза реконструкции 1318/1318 символов, table 3/3, 3/3 сегмента, body сегментов 1 и 3 байт-в-байт, right всех трёх сегментов байт-в-байт, 6 промптов сквозными. В body сегмента 2 разница ровно 2 байта — пропущенный союз «И в этом» в эталоне (ошибка ручной сборки JSON, парсер взял правильный текст из MD). Это и есть ценность рефакторинга: ручная сборка давала случайные пропуски, парсер их не делает.

**Реализация — Codex 5.5 как исполнитель по подробному плану.** Координатор Opus написал план на 13 задач (каждая = чистая функция + sanity-check + commit). Перед передачей агенту — повторный проход по плану свежим глазом, нашли дыру: пробел между `</strong>` и `<ol>/<ul>` в blockquote-блоках с нумерованным списком терялся. Все 13 задач прошли без переделок: цена ревью плана 15 минут, отдача — 0 итераций фикса у Codex.

## Известные риски

- Метка blockquote с двумя `:` внутри (`**Пример: вот так:**`) сломает регулярку — `MasterMDParseError`. В текущих мастер-MD таких нет.
- HTML-escape прозы не делается (внутри fenced — делается). Литеральные `<`/`>`/`&` в прозе попадут как есть.
- Парсинг badge зависит от структуры `Курс. Модуль N. Урок K: тема` — > 3 частей до `:` дадут только первые две в badge.
