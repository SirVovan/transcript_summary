## Тикет 1 — убрать лишнюю строку-эхо про (И)→(М)→(Д)

**Файл:** `.claude/skills/konspekt/SKILL.md`

**Контекст:** Полное объяснение мысленного инструмента (И)→(М)→(Д) даётся один раз в блоке «Три уровня (И)/(М)/(Д) — внутренний инструмент агента» (~строки 323-339). Строка 339 уже явно говорит: «Перед написанием сегментов **и в Самопроверке** мысленно собираешь дугу…» — то есть заранее указывает, что это нужно повторить и на этапе самопроверки. Несмотря на это, в разделе «Ориентиры при чтении» ШАГ 3 (Самопроверка) есть отдельная строка, дословно повторяющая то же самое.

**Правка:** В разделе ШАГ 3 «Ориентиры при чтении (не для отчёта)» найти строку:

```
- **Сквозная цепочка (И)→(М)→(Д) собирается мысленно** — все ли сегменты раскрывают Главную мысль из шапки, видно ли движение идея→метод→действие?
```

Удалить её целиком (это отдельный буллет списка). Остальные буллеты этого списка и весь раздел «Три уровня (И)/(М)/(Д)» (строки 323-339) не трогать.

## Тикет 2 — развести формулировки двух блоков самопроверки

**Файл:** `.claude/skills/konspekt/SKILL.md`

**Контекст:** Есть два блока самопроверки в разных точках пайплайна:
1. Форсирующая самопроверка в ШАГ 1.4 — проверяет **карту сегментов до написания текста**.
2. Самопроверка в ШАГ 3 — проверяет **уже готовый, полностью написанный текст**.

Оба сейчас сформулированы похожей структурой («встань на место читателя, пройди сверху вниз»), из-за чего читаются как копия друг друга. Оставить оба блока по содержанию, но переформулировать вводные фразы/заголовки каждого так, чтобы сразу было понятно, какой именно момент пайплайна и какой артефакт проверяется.

**Правка:**
- Найти вводную формулировку форсирующей самопроверки в ШАГ 1.4 (перед показом карты пользователю) — переписать так, чтобы явно называла: «это проверка **карты сегментов**, до того как написан текст».
- Найти вводную формулировку самопроверки ШАГ 3 — переписать так, чтобы явно называла: «это проверка **готового, полностью написанного мастер-MD**, после того как весь текст готов».
- Сам список критериев/буллетов внутри каждого блока не менять — только вводную рамку/заголовок каждого блока.

## Тикет 5 — убрать ритуал «прочитай вслух»

**Файл:** `.claude/skills/konspekt/layer3_recon.md`

**Контекст:** В разделе «Язык» есть строка (~строка 65):

```
**Тест:** прочитай абзац вслух. Если он звучит как человек объясняет суть урока — нормально. Если как литературовед или преподаватель риторики — переписывай.
```

Критерий «звучит как человек объясняет vs как литературовед» пересекается с пунктом «Литературоведческий разбор» в разделе «Антипаттерны» (сохраняется тикетом 4). Императив «прочитай вслух» — лишний физический ритуал, не нужен под Opus.

**Правка:** Заменить строку на критерий без физического действия, например:

```
**Тест:** звучит ли абзац как человек объясняет суть урока другому человеку, а не как литературовед или преподаватель риторики?
```

(Точную формулировку агент может слегка адаптировать под стиль соседних строк файла — суть: убрать «прочитай вслух», оставить сам критерий.)
