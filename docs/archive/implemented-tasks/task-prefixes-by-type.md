# Задание: перевод имён `/konspekt` на префиксы по типу (MASTER_/REVIEW_/WIDGET_)

> Самодостаточное задание для автономной сессии. Все дизайн-решения **уже приняты**
> (см. раздел «Решения»). Не переспрашивай по ним — кроме гейта чистоты дерева (Шаг 0).

## Контекст

Хранилище материалов перешло на новый словарь префиксов: тип продукта читается из
**префикса имени файла**, хвостовых суффиксов (`_обзор`/`_мастер`/`_виджет`) больше нет.

- `SRC_` — первоисточник (транскрипт, оригинал) — **не трогаем**
- `MASTER_` — мастер-конспект (был `OUT_…_мастер.md`)
- `REVIEW_` — обзор (был `OUT_…_обзор.md`)
- `WIDGET_` — виджет (был `OUT_…_виджет.html` / `Виджет — ….html`)
- `SEC_` — обслуга (`SEC_tov_<серия>.md` и пр.) — **не трогаем**

Реальные файлы в архиве `F:\Наш Архив\ИИ\Ролики\` уже переименованы под эту схему
(2026-06-27). Курсы (`Обучение`/папки авторов) **сознательно НЕ переименованы** —
там мастера остаются `OUT_*_мастер.md`. Скилл `/konspekt` всё ещё генерирует и ищет
старые имена — эта задача переводит его на новый словарь, **не ломая существующие курсы**.

## Решения (приняты, не пересматривать)

1. **Курсы остаются на `OUT_`.** Автопоиск серии должен находить **оба** паттерна:
   новый `MASTER_*.md` и старый `OUT_*_мастер.md`. Массовое переименование курсов
   в объём НЕ входит (это отдельный риск по живым данным). → двойной поиск.
2. **Тело имени не меняем** — только префикс и хвостовой суффикс. Формат «автора в
   имени» оставляем как есть: master — `MASTER_[название].md` (без автора, как было),
   preview — `REVIEW_<Канал>_<название>.md` (канал в префиксе сохраняется, как было).
3. **`SRC_`/`SEC_` и slug-формула не трогаются** (см. «Не трогать»).

## Правки генерации имён (выход)

Якоря — grep по паттернам (номера строк ориентировочны, после правок съедут).

| Файл | Якорь (grep) | Было → стало |
|---|---|---|
| `SKILL.md` | `OUT_[название]_мастер.md`, `_чN_мастер.md`, отчёт «Мастер-MD готов» | `MASTER_[название].md` |
| `preview.md` | `OUT_<Канал>_<название>_обзор.md`, `OUT_<название>_обзор.md`, отчёт «Обзор готов» | `REVIEW_<Канал>_<название>.md` |
| `layer2_widget.md` | команда `widget_generator.py …_мастер.md`; «`Виджет — [Название].html`»; резерв `Виджет — [Название].json` | вход `MASTER_[Название].md`; выход `WIDGET_[Название].html` / `.json` |
| `md_parser.py` | `out_stem = re.sub(r'_мастер$', '', stem)` / `out = f"Виджет — {out_stem}.html"` | **сменить логику:** заменять префикс `MASTER_` → `WIDGET_` (`re.sub(r'^MASTER_', 'WIDGET_', stem)`), результат `f"{out_stem}.html"`. Fallback для имён без префикса `MASTER_`: оставить прежнее поведение (`Виджет — {stem}.html`) либо просто `{stem}.html` — на выбор реализующего, лишь бы тест проходил |

## Готовность (Definition of Done)

1. Все места из таблиц обновлены (grep по `_мастер.md`/`_обзор.md`/`Виджет —`/`OUT_…_`

2. `md_parser`: `MASTER_X.md` → `WIDGET_X.html`, покрыто тестом.
3. Автопоиск серии находит и `MASTER_*`, и `OUT_*_мастер.md`.
4. `pytest` зелёный.
5. Работа в отдельной ветке; **коммит локальный, без push и без PR** (push сделает
   пользователь сам).
