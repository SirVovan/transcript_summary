# Архив отработанных материалов

Сюда складываются **отработавшие** одноразовые документы (хэндофы переноса контекста,
промпты для сессий, спеки закрытых задач), чтобы они не замусоривали корень репо и `docs/`.
Постоянный архив эволюции скилла — отдельно, в `docs/evolution/`.

## Содержимое

- **`konspekt-widget-frames/`** — эпопея «виджет с кадрами»: хэндофы и промпты сессий
  по реализации извлечения кадров, покрытию сегментов, ревью Codex и E2E-прогонам.
  Работа велась в ветке `feat/konspekt-widget-frames`.
- **`misc-handoffs/`** — разрозненные отработавшие хэндофы прошлых задач
  (адаптив виджета под телефон, проблемы сегментации).
- **`implemented-tasks/`** — спеки задач, уже внедрённых в скилл
  (префиксы `MASTER_/REVIEW_/WIDGET_`, дообучение сегментации и заголовков).
- **`superpowers/`** — планы и спеки (writing-plans/executing-plans) по **внедрённым**
  фичам ядра скилла: layer1/2, mastermd-форматирование, md-parser, route-блок, preview.
  Живые (ветка кадров) и tg-bot остались в `docs/superpowers/`.
