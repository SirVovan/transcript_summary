## Цель
Добавить в **ветку виджета** `/konspekt` opt-in извлечение ключевых кадров видео (слайды, промпты, инфографика): найти → заскринить → распознать. ## Ключевые решения (и почему)
- **Скоуп — только виджет** (не master-MD/preview): один выход, есть естественное место под картинки, минимум риска.
- **Источник кадров**: и yt-dlp (URL из шапки транскрипта `source:`), и локальный mp4/webm.
- **Детекция — гибрид**: ffmpeg scene-detection (порог 0.3) + transcript-cues → кандидаты; финальный отсев за vision.
- **Два прохода**: contact-sheet триаж (дёшево) → full-res разбор shortlist (точно). Идея Codex — снижает токены и повышает надёжность на длинных видео.
- **Vision-движок — Codex 5.5 при доступности, иначе актуальный Sonnet.** Проверено вживую: `codex exec -i <img>` на `gpt-5.5` читает кириллицу **дословно** и классифицирует; работает **на бюджете OpenAI, вне Claude-токенов** — главная экономия. JSON через `--output-schema`. Модели через алиасы, **версии не хардкодить**.
- **Codex НЕ путать**: он и пишет код фичи, и делает рантайм-vision (читает картинки). «Не рисует растр» ≠ «не видит растр» — прежняя заметка памяти была про генерацию, исправлена.
- **Встраивание (подход A)**: кадры вписываются в **производную копию** `MASTER_[Название]_с_кадрами.md` (оригинал-продукт не трогаем), виджет собирается из неё → `WIDGET_[Название].html`. Текст переиспользует блок промпта/спецблок (код не нужен), иллюстрация — новый элемент `![](path)` → base64-`<figure>`.
- **Фаза 0 — миграция имён** на префиксы `MASTER_`/`REVIEW_`/`WIDGET_` (по `docs/task-prefixes-by-type.md`), т.к. ветка всё равно правит те же файлы. Обзор = **REVIEW_**, не PREVIEW_ (пользователь оговорился). Курсы остаются на `OUT_*_мастер.md` → двойной автопоиск.
- **Мастер-MD режим остаётся на Opus**; 1М-контекст Sonnet тут не нужен (транскрипты влезают в 200К), качество сегментации/заголовков дошлифовано под Опус. A/B Sonnet — отдельный эксперимент позже.

## Грабли / чего избегать
- `_parse_segment` ([md_parser.py:319](.claude/skills/konspekt/md_parser.py#L319)) требует СТРОГИЙ формат: `## Сегмент N | HH:MM:SS-HH:MM:SS | Тема` + `**Тип:**` + `**Ключевая мысль:**`, порядок `### Карта` → `### Текст`. Тестовые фикстуры обязаны это соблюдать (в плане — хелпер `_master()`). Первая версия плана падала на этом — Codex поймал.
- Инвариант: `MASTER_X_с_кадрами.md` → `WIDGET_X.html` (снять суффикс `_с_кадрами` в `_parse_meta`), иначе имя выхода кривое.
- `validate_widget.py:27` матчит только `Виджет.*\.html` — после миграции обновить под `WIDGET_*.html`, иначе hook-валидатор молча перестанет работать.
- `contact_sheet` делать на **PIL** (Pillow 12.2 есть), номера из имени `cand_NNNN.png` — надёжнее ffmpeg-`tile`. Не читать `cand_%04d.png` шаблоном, строить из списка кадров.
- ffmpeg/yt-dlp-обёртки проверять `returncode` (не молчаливый пустой список). `-ss` перед `-i` = быстрый seek (для слайдов ок).
- `_render_image`: `html.escape(alt, quote=True)` — иначе кавычки в alt ломают атрибут.
- Тело сегмента уходит в виджет как JS-строка (`var BODY`), base64 в ней безопасен.
