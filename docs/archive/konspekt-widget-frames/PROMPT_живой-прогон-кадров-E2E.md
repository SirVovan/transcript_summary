## Шаги (по разделу «Opt-in ветка: виджет с кадрами» в `layer2_widget.md`)
1. **Dry-run кандидатов:**
   ```bash
   PYTHONUTF8=1 python .claude/skills/konspekt/frames_extract.py \
     --url "<YouTube-URL>"  (или --video "<путь.mp4>") \
     --srt "<путь к .srt>" \
     --work-dir "<рабочая-папка>/frames_work" \
     --dry-run
   ```
   Проверь: собралась `contact_sheet.png`, число кандидатов **в разумных пределах** (не сотни). Если сотни — подкрути `--threshold` или лимиты.
2. **Триаж по простыне** → shortlist (Codex-команда из `layer2_widget.md`, при недоступности — субагент актуального Sonnet). Отбрось `type=drop`.
3. **Full-res разбор** shortlist (Codex/Sonnet) + политика уверенности: при сомнении в дословности промпта → `type=illustration` с пометкой «проверить».
4. **Вписать кадры в производную копию** `MASTER_[Название]_с_кадрами.md` (ОРИГИНАЛ не трогать): текст (prompt/slide-text) → блок промпта/спецблок; иллюстрация → `![подпись · таймкод](frames_work/cand_NN.png)`.
5. **Собрать виджет** из копии:
   ```bash
   PYTHONUTF8=1 python .claude/skills/konspekt/widget_generator.py "<...>/MASTER_[Название]_с_кадрами.md"
   ```
   Ожидание: `✅ JS syntax OK`, создан `WIDGET_[Название].html` (суффикс `_с_кадрами` в имя не переносится).

## Проверка глазами (открыть виджет в браузере)
- Кадры стоят в нужных сегментах (привязка по таймкоду верна).
- Промпты распознаны **дословно** и **копируются**.
- Иллюстрации видны, подписи на месте.
- Вес HTML **≤ 8 МБ**.
- Мягкая деградация: если убрать видео/ffmpeg/cookies — собирается обычный виджет без кадров, без падений.

## Зафиксировать наблюдения
- Что отобралось/распозналось плохо → в `backlog.md` или подкрути пороги/лимиты (и обсуди со мной).
- **Артефакты прогона НЕ коммитить** (видео, `frames_work/`, копию MD, виджет) — это продукты в K_T_P; `frames_work/` уже в `.gitignore`.
- Язык — русский. При развилках — уточняй, молча не выбирай.

Собран `WIDGET_[Название].html` с реально встроенными кадрами; глазами подтверждено, что кадры на местах, промпты дословны и копируются, вес в норме; наблюдения записаны. Если что-то системно плохо — список правок для следующей сессии.
