## Ключевые точки спеки, которые план должен покрыть явно

1. `segment_bounds()` — новый независимый парсер границ сегментов из мастер-MD (не переиспользует `md_parser.py`), с валидацией монотонности/непересечения.
2. `phash_dedup()` — average-hash на PIL, скользящее окно N=3 (не только сравнение с предыдущим кадром).
3. Посегментные квоты в `build_candidates` + fallback-пересчёт при превышении общего предохранителя (150).
4. Явный порядок «Шаг 2 (триаж всех кандидатов, без отбора) → детерминированный двухфазный отбор (обязательная фаза + бюджет) в главном потоке → Шаг 3 (full-res только отобранных)» — это меняет роль текущего Шага 2 в `layer2_widget.md`.
5. Удаление `segment_hint` из `frames_schema.json` + явный join vision-результата с `candidates.json` по `cand_id`.
6. Адаптивный потолок `max(12, сегментов + 10)` + процедура разрешения конфликта с весом ≤8 МБ (сжатие → урезка фазы бюджета по возрастанию confidence → деградация с предупреждением).
7. Отчёт (Шаг 6) — таблица по сегментам (кандидатов / прошло триаж / вставлено).
8. Исправить устаревшую фразу в `layer2_widget.md` про отсутствие таймкодов у сегментов.
