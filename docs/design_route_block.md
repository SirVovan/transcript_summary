# Дизайн: «Карта замысла» в мастер-MD как основа Слоя 3

> Статус: **брейнсторминг почти завершён, не реализовано.** Обсуждение начато 2026-05-25
> в диалоге про У12, вынесено в отдельный диалог из-за перегруза контекста.
> Продолжить отсюда: остался выбор имени блока и презентация остальных разделов дизайна.

## Проблема

Маршрут / сквозная линия урока сейчас рождается на этапе Слоя 3 (оформление виджета),
а должна — на этапе мастер-файла (осмысление). Это давняя цель пользователя, которую он
раньше не мог сформулировать. В прошлый раз попытка реализовать вылилась в Слой 3; он
неплохо работает, поэтому процесс не ломали. Сейчас пересматриваем.

## К чему пришли (согласовано с пользователем)

- **Маршрут первичен по отношению к сегментации.** Строится в ШАГ 1 мастер-файла **до**
  сегментации: сегменты должны быть этапами единого замысла автора, а не разрозненными
  кусками, к которым задним числом подбирается общая нить.
- **«Маршрут» и «взгляд сверху» Слоя 3 — одна сущность под двумя углами** (оба дают
  целостную картину без вязки в деталях), а не два блока. Дублирование исчезает не
  выкидыванием одной части, а разнесением по этажам: смысл → мастер-файл, оформление → Слой 3.
- **Вид блока — (б): проза «взгляд сверху» + явная нумерованная лестница «Этапы» со
  стрелками**, в одном разделе мастер-MD, сразу после шапки.
- **Слой 3 перестаёт сочинять взгляд сверху**, становится графическим + текстовым
  оформлением готового блока: верстает прозу в левую колонку, рисует SVG по этапам
  маршрута, не изобретает смысл. «Взгляд сверху» НЕ выбрасывать — он хорошо работает.
- **Блок условный**: только для уроков с единым замыслом (лекция-методология, серия,
  объединённый урок). Для разрозненного контента блока нет; парсер должен принимать
  оба случая — с блоком и без.
- **Имя блока:** кандидаты «Карта замысла» (рекомендация Claude) vs «Маршрут урока».
  **Не выбрано.**

## Что трогать (Подход А)

- `SKILL.md` — методология ШАГ 1 (маршрут до сегментации) + критерий условности блока.
- `md_parser.py` — читать раздел, отдавать как `route` в data, не падать без него.
- `layer3_recon.md` — брать `route` за основу левой колонки и SVG, не сочинять заново.

Опасение пользователя — **не сломать работающий Слой 3.**

## Связь с существующим

`profile_lecture.md` уже требует «сегменты = ШАГИ единого процесса, сквозная нумерация» —
новый блок достраивает это, не вводит чужую концепцию. Маршрут — недостающее среднее
звено между Главной мыслью шапки (*что* доносит автор) и цепочкой И→М→Д (*на каком
уровне абстракции*): маршрут отвечает *в каком порядке и почему именно так*.

## Черновик структуры блока (из обсуждения)

```markdown
## Карта замысла

[Проза «взгляд сверху»: 4–6 коротких абзацев. О чём урок, что автор доносит,
как устроена логика, есть ли поворот. Простым языком. Жирное = сжатая мысль абзаца.]

**Этапы:**

1. **Этап 1 — <глагол>: <суть>** — почему отсюда начинаем / что даёт.
2. **Этап 2 — <глагол>: <суть>** — почему за предыдущим следует это.
   ...
*(для объединённых уроков — пометка шва между частями отдельной строкой)*
```

Рабочий пример блока был написан для У12 (потом удалён из мастер-MD, т.к. парсер его
ещё не знает) — см. историю файла
`OUT_Вайбкодинг. М2-У12 (ч1+ч2)...мастер.md`.
